# Kallia

Projeto de website desenvolvido durante o curso de Desenvolvimento de Software Multiplataforma da Fatec.

O site apresenta uma empresa fictícia especializada em móveis planejados e design de interiores.

## Demonstração

![Apresentação do site Kallia](./imagem/site.webp)


## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Ionicons

## Funcionalidades

- Layout responsivo
- Menu de navegação
- Apresentação de ambientes
- Área institucional
- Depoimentos de clientes
- Formulário de cadastro
- Tabela de informações
- Seção de contato

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
